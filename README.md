# project-uricoechea

Vocabulary and identifiers of a pilot digital edition of works by Ezequiel Uricoechea. Static files only, served with GitHub Pages.

- `vocab/1.0/`: the vocabulary of the project (namespace `https://w3id.org/project-uricoechea/vocab/1.0#`, registration at w3id.org pending): `profile.ttl` (terms and values) and `shapes.ttl` (SHACL shapes), with a short page that lists the terms.
- `data/`: a page that says the data are not published yet. It is the target of `https://w3id.org/project-uricoechea/data/` until they are.

`profile.ttl` and `shapes.ttl` are **copies**: the source is the `schema/` folder of the project's pipeline, which is not public. The version `1.0` changes only when a term is renamed or its meaning changes.
